# Annex IV §2(g) — Accuracy of the AI system on the held-out evaluation set

- **standard**: EU_AI_ACT (Regulation (EU) 2024/1689, Annex IV)
- **datapoint**: `AIACT_ANNEX-IV-2_evaluation_accuracy`
- **kind**: quantitative
- **reporting period basis**: point_in_time
- **unit**: ratio (published to 4 dp)

## What the clause requires

Accuracy measured on the held-out evaluation set described in the data sheet, reported as a ratio, together with the metric definition used.

## Methodology as declared

Proportion of correct predictions over the held-out evaluation set, computed from the recorded evaluation run. The figure is not taken from a summary document: it is recomputed from the run's own outputs, and cross-checked against the confusion matrix.

## Evidence the undertaking must hold

Documents of class `data_sheet`, `evaluation_report`; at least 2, not necessarily within the reporting period.

## Lawful omissions

None. This datapoint has no permitted omission.

Anything else that prevents disclosure is an internal failure, not an omission: the report does not issue, and the reason code says so on the face of the statement.
