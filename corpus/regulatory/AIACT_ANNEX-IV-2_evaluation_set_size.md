# Annex IV §2(d) — Size of the held-out evaluation set

- **standard**: EU_AI_ACT (Regulation (EU) 2024/1689, Annex IV)
- **datapoint**: `AIACT_ANNEX-IV-2_evaluation_set_size`
- **kind**: quantitative
- **reporting period basis**: point_in_time
- **unit**: count (published to 0 dp)

## What the clause requires

Number of examples in the held-out evaluation set on which the reported accuracy was measured.

## Methodology as declared

Count of distinct examples in the evaluation split, excluding any example that also appears in training. An accuracy figure without the size of the set it was measured on is not a measurement, and the two are disclosed together for that reason.

## Evidence the undertaking must hold

Documents of class `data_sheet`; at least 1, not necessarily within the reporting period.

## Lawful omissions

None. This datapoint has no permitted omission.

Anything else that prevents disclosure is an internal failure, not an omission: the report does not issue, and the reason code says so on the face of the statement.
